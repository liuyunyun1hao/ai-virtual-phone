# 1.1.1 · 性能与数据保护更新

2026-10-18

## 聊天与大存档性能优化

减少头像、身份和相册后台读取时的重复历史扫描；启动时分批加载公共和当前身份数据，降低不必要的处理开销。

## 按身份备份与恢复

文件和云备份支持选择当前身份或全部身份，保留私人数据归属；导入前检查备份，旧格式可迁入新身份。

## 导入冲突可分别处理

恢复时默认保留本机冲突项，可分别选择覆盖私人数据和公共档案；云端按备份范围保留历史备份。

## 身份删除与恢复保护

删除受阻或恢复中断时保留恢复数据和处理进度，支持后续重试，避免提前清除关联图片。

## 相册与媒体维护优化

相册讨论改为逐条保存，旧图片迁移失败时保留来源；媒体维护分批处理，并在清理前复查收藏和内容变化。

## 长期数据与写入保护

头像历史等长期数据不再误归缓存；旧数据迁移成功后才移除来源，写入失败提供提示和重试。

## 更新方法

先导出重要数据备份，再在自己的 GitHub fork 中选择 Sync fork → Update branch，并等待或手动触发托管平台重新部署。使用原网址打开。

升级前保存的备份请继续保留。iOS/PWA 大存档长期运行、低空间及真实云端场景仍需实际使用验证；恢复中断时可能按进度续做，不代表整包原子回滚。
